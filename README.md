### Bright Steps - Home Tutors & Coaching Centre
#### Empowering Young Minds through Quality Education 📚

📖 Description
---------------
Bright Steps is a static website designed for a home tutoring and coaching centre. The website aims to provide a user-friendly interface for parents and students to explore the services offered by the centre, including subject-wise tutoring, coaching classes, and other educational resources. The website is built using HTML, CSS, and JavaScript, ensuring a seamless and engaging user experience.

The website features a clean and modern design, with easy navigation and accessible content. The homepage showcases the centre's mission, vision, and values, along with a brief overview of the services offered. The website also includes a dedicated section for testimonials, where parents and students can share their experiences and feedback about the centre. Additionally, the website provides a contact form and address details, making it easy for users to get in touch with the centre.

The development of this website is focused on providing a simple, yet effective, online presence for the Bright Steps coaching centre. By leveraging the latest web technologies and design principles, the website aims to establish a strong brand identity and attract potential customers. With its intuitive interface and informative content, the website is an ideal platform for parents and students to discover the centre's services and benefits.

✨ Features
-----------
Here are some of the key features of the Bright Steps website:
* **Responsive Design**: The website is optimized for various devices and screen sizes, ensuring a consistent user experience across different platforms.
* **Easy Navigation**: The website features a simple and intuitive navigation menu, allowing users to quickly access different sections and pages.
* **Service Overview**: The website provides a comprehensive overview of the centre's services, including subject-wise tutoring and coaching classes.
* **Testimonials**: The website includes a dedicated section for testimonials, where parents and students can share their experiences and feedback about the centre.
* **Contact Form**: The website features a contact form, making it easy for users to get in touch with the centre and inquire about services.
* **Address Details**: The website provides detailed address information, including maps and directions, to help users locate the centre.
* **Social Media Integration**: The website includes links to the centre's social media profiles, allowing users to stay updated about the latest news and events.
* **FAQ Section**: The website features a frequently asked questions (FAQ) section, providing answers to common queries and concerns.

📁 Project Structure
---------------------
The project directory is organized into the following folders and files:
* **index.html**: The main entry point of the website, containing the HTML structure and content.
* **styles**: A folder containing the CSS styles and layouts for the website.
	+ **style.css**: The primary CSS file, defining the visual styles and layouts for the website.
* **scripts**: A folder containing the JavaScript files for the website.
	+ **script.js**: The primary JavaScript file, handling user interactions and dynamic effects.
* **images**: A folder containing the image assets used on the website.
* **fonts**: A folder containing the font files used on the website.
* **vendors**: A folder containing third-party libraries and tools, such as Font Awesome.
